# Lộ trình sau v0.6

1. Storage (kho lưu trữ) S3-compatible và Signed URL (đã có nền tảng ở v0.6).
2. Thay session Admin trong RAM bằng session/token bền vững và mật khẩu băm.
3. Phân quyền Admin và rate limiting (giới hạn tần suất).
4. Audit log (nhật ký thao tác).
5. Tìm kiếm/lọc và giao diện hoàn thiện.
6. Test (kiểm thử) Backend + Frontend.
7. Deploy (đưa lên Internet) với HTTPS.
